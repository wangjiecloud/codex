# 产业链页面股票搜索功能

## 功能概述

在产业链分析页面的header中增加了股票搜索功能，支持快速定位和跳转到包含特定股票的供应链节点。

## 功能特性

### 1. 搜索框位置
- 位置：页面header右侧，"供应链图谱/产业解剖"切换按钮之前
- 宽度：256px (w-64)
- 样式：深色主题，与页面整体风格一致

### 2. 模糊搜索
**触发条件**:
- 输入至少1个字符即开始搜索
- 支持搜索股票代码和股票名称
- 不区分大小写

**搜索逻辑**:
```typescript
// 匹配规则：包含查询字符串
stock.code.toLowerCase().includes(query) ||
stock.name.toLowerCase().includes(query)
```

**示例**:
- 输入 "东材" → 匹配 "东材科技"
- 输入 "601" → 匹配 "601208东材科技"
- 输入 "宁德" → 匹配 "宁德时代"

### 3. 下拉搜索结果
**显示条件**:
- 有搜索结果时自动显示
- 点击外部区域自动关闭
- 按ESC键关闭

**结果展示**:
- 左侧：股票名称（白色）
- 右侧：股票代码（灰色）
- 悬停：背景色变化 (#252a3a)
- 最大高度：320px，超出可滚动

**样式**:
```css
background: #1a1f2e
border: #1e2332
max-height: 320px (20rem)
overflow-y: auto
```

### 4. 快捷键支持

| 按键 | 功能 |
|------|------|
| Enter | 跳转到第一个搜索结果 |
| Escape | 清空搜索并关闭下拉框 |
| 点击×按钮 | 清空搜索内容 |

### 5. 跳转行为

**触发方式**:
- 按回车键（跳转到第一个结果）
- 点击下拉列表中的某个结果

**跳转动作**:
1. 切换到"供应链图谱"视图 (setActiveTab("chain"))
2. 选中包含该股票的节点 (setSelectedId(result.nodeId))
3. 清空搜索框
4. 关闭下拉列表

**效果**:
- 自动切换到供应链图谱视图
- 高亮显示包含该股票的供应链节点
- 右侧面板显示该节点的详细信息

## 技术实现

### 状态管理
```typescript
const [searchQuery, setSearchQuery] = useState("");
const [searchResults, setSearchResults] = useState<
  Array<{ code: string; name: string; nodeId: string }>
>([]);
const [showSearchDropdown, setShowSearchDropdown] = useState(false);
const searchInputRef = useRef<HTMLInputElement>(null);
```

### 搜索逻辑
```typescript
useEffect(() => {
  if (searchQuery.trim().length === 0) {
    setSearchResults([]);
    setShowSearchDropdown(false);
    return;
  }

  const query = searchQuery.toLowerCase();
  const results: Array<{ code: string; name: string; nodeId: string }> = [];

  nodes.forEach((node) => {
    const stocks = node.data.stocks || [];
    stocks.forEach((stock) => {
      if (
        stock.code.toLowerCase().includes(query) ||
        stock.name.toLowerCase().includes(query)
      ) {
        results.push({
          code: stock.code,
          name: stock.name,
          nodeId: node.id,
        });
      }
    });
  });

  setSearchResults(results);
  setShowSearchDropdown(results.length > 0);
}, [searchQuery, nodes]);
```

### 跳转处理
```typescript
const handleSearchSelect = useCallback(
  (result: { code: string; name: string; nodeId: string }) => {
    setActiveTab("chain");
    setSelectedId(result.nodeId);
    setSearchQuery("");
    setShowSearchDropdown(false);
  },
  [],
);
```

### 点击外部关闭
```typescript
useEffect(() => {
  const handleClickOutside = (event: MouseEvent) => {
    if (
      searchInputRef.current &&
      !searchInputRef.current.contains(event.target as HTMLElement)
    ) {
      setShowSearchDropdown(false);
    }
  };

  document.addEventListener("mousedown", handleClickOutside);
  return () => document.removeEventListener("mousedown", handleClickOutside);
}, []);
```

## 使用场景

### 场景1: 快速定位特定股票
1. 用户想查看"宁德时代"在哪个产业链环节
2. 在搜索框输入"宁德"或"300750"
3. 下拉框显示匹配结果
4. 点击或按回车
5. 自动跳转到供应链图谱并高亮相应节点

### 场景2: 浏览相似股票
1. 输入"科技"
2. 查看所有包含"科技"的股票列表
3. 逐个点击查看不同公司在产业链中的位置

### 场景3: 通过代码精确查找
1. 输入完整股票代码"601208"
2. 精确匹配到"东材科技"
3. 快速跳转

## 注意事项

1. **搜索范围**: 只搜索当前产业链中的股票，不跨产业链搜索
2. **重复结果**: 如果一个股票出现在多个节点中，会显示多条结果
3. **实时更新**: 当nodes数据变化时，搜索结果会自动更新
4. **性能**: 使用useEffect + useMemo优化，避免每次输入都遍历所有节点
